# 연금 비교 설계 앱 (pension-compare-app)

국민연금·공적연금·퇴직연금·개인연금 정보를 넣으면 나이별 예상 수령액, 세금·건강보험 영향, 부부 유족연금 시나리오, "같은 돈이면 어디가 나은지" 비교까지 한 번에 보여주는 상담용 웹앱이에요.

## 보는 법

이 저장소를 GitHub Pages로 켜두면 아래 주소에서 바로 열 수 있어요.

```
https://<깃허브계정>.github.io/pension-compare-app/
```

## 파일 구조

- `index.html` — 앱 전체(HTML/CSS/JS가 한 파일에 다 들어있어요). 이 파일만 수정하고 커밋·푸시하면 자동으로 배포돼요.

## 업데이트 방법

1. `index.html`을 새 버전으로 교체해요.
2. GitHub Desktop에서 변경사항을 커밋해요.
3. Push 하면 1~2분 안에 실제 사이트에 반영돼요 (별도 배포 작업 필요 없음).

## 참고

이 앱의 모든 계산은 상담용 간이 추정식이에요. 실제 수령액·세금·건강보험료는 국민연금공단·국세청·건강보험공단 최신 자료로 다시 확인해주세요.
